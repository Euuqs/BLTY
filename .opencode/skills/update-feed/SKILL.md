# 更新动态 · Feed

为「柏里挑怡」应援站添加或更新动态条目（路透、日常、舞台、采访等），以时间线形式展示。

## 触发场景

当用户提到以下内容时使用此 Skill：
- "添加动态"、"更新动态"、"新增动态"
- "发路透"、"有个机场图"、"今天舞台好绝"、"微博更新了"
- 任何需要记录在时间线上的日常/活动/舞台事件

## 项目路径

- 内容目录：`D:\projects\cp-site\content\feeds\`
- Schema 定义：`D:\projects\cp-site\velite.config.ts` 中的 `feeds` collection
- 展示页面：`D:\projects\cp-site\src\app\feed\page.tsx`（时间线布局，新→旧排序）

## MDX Frontmatter 字段规范

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| `title` | string (max 99) | ✅ | 动态标题，简短醒目 | "机场出发，两人同框"、"柏欣妤微博更新自拍" |
| `date` | ISO date (YYYY-MM-DD) | ✅ | 动态发生日期 | "2026-08-01" |
| `member` | enum | ✅ | 主角成员 | `A`=柏欣妤，`B`=朱怡欣，`both`=双人/CP |
| `type` | enum | ❌ | 动态类型 | `路透`、`日常`、`舞台`、`采访`、`其他` |
| `description` | string | ❌ | 简短描述（一句话概括） | "今天长沙出发机场，两人并排走" |
| `tags` | string[] | ❌ | 标签数组 | ["机场", "糖", "路透"] |

## Body 内容

frontmatter 下方可写详细内容（糖点描述、舞台感想、配图说明等），支持 GFM。

## 操作步骤

1. **确认信息**：如缺日期/主角/内容，先询问
2. **创建 MDX 文件**：在 `content/feeds/` 下新建 `.mdx` 文件，文件名用简短拼音/英文（如 `jichang-tongkuang.mdx`）
3. **填写 frontmatter**：严格按字段规范
4. **验证构建**：删除 `.next` 缓存，运行 `npm.cmd run build`
5. **启动预览**（可选）：`npm.cmd run dev`，查看 http://localhost:3000/feed

## 批量上传（一次添加多条动态）

当用户一次性提供多条动态时，可批量创建，无需逐条单独执行流程：

1. **解析条目**：从用户聊天中拆分为多条，每条包含 `title`/`date`/`member`（/`type`/`description`/`tags`）；缺失字段集中询问一次
2. **逐条创建文件**：在 `content/feeds/` 下为每条新建 `.mdx` 文件
3. **命名防冲突**：同一日期多条时，文件名加序号或时间后缀（如 `airport-0728-01.mdx`、`weibo-0728-02.mdx`）
4. **检查去重**：核对已有文件（如 `airport-july28.mdx`），避免重复添加
5. **统一验证**：全部文件写完后，删除 `.next` 缓存，运行 `npm.cmd run build` 一次即可
6. **预览**：`npm.cmd run dev` 查看 http://localhost:3000/feed

### 推荐输入格式（结构化字段块）

每条一个字段块，条目间用空行分隔，最稳且解析无歧义：

```text
标题：机场出发，两人同框
日期：2026-08-01
成员：both
类型：路透
描述：柏欣妤帮朱怡欣拎包，两人笑得很甜
标签：机场, 糖, 路透

标题：柏欣妤微博自拍更新
日期：2026-08-01
成员：A
标签：日常, 自拍
```

- 每条必须：`标题`/`日期`/`成员`
- 可选：`类型`/`描述`/`标签`（多个标签用逗号分隔）
- 用户若直接粘贴自然语言，也可按相同字段解析补全

批量注意：每条仍是独立 `.mdx` 文件（一动态一文件），页面自动按日期倒序展示，无需手动排序。

## 动态类型枚举

- `路透` — 机场/上下班/外出路透、粉丝偶遇
- `日常` — 微博/小红书/抖音日常更新、自拍
- `舞台` — 舞台直拍、演出记录、ending pose
- `采访` — 媒体采访、杂志、访谈
- `其他` — 不属于以上类型

## 成员速查

| 值 | 成员 | 时间线圆点 |
|----|------|-----------|
| `A` | 柏欣妤 | 白色圆点 (dot-bai) |
| `B` | 朱怡欣 | 蓝色圆点 (dot-zhu) |
| `both` | 双人/CP | 紫色圆点 (dot-cp) |

## 文件示例

```mdx
---
title: "机场出发，两人同框"
date: 2026-07-28
member: both
type: 路透
description: "今天长沙出发机场，两人并排走，柏欣妤帮朱怡欣拎包了！"
tags: ["机场", "糖", "路透"]
---

今天机场糖点：柏欣妤主动帮朱怡欣拎包，两人笑的很甜。
柏里挑怡是真的！！
```

## 注意事项

- 动态以时间线形式展示，最新的在最上面（自动按日期倒序）
- `tags` 会以紫色小标签显示在卡片底部
- `description` 显示在标题下方作为摘要，body 内容写详细描述
- 标题要醒目简洁，吸引读者点击
- 写完务必构建验证
