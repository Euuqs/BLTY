## 设计原则（确认约束）

1. **延续三色体系**：柏欣妤=白、朱怡欣=蓝、CP=紫，不引入新色相，只强化使用场景。
2. **动效克制**：所有动画尊重 `prefers-reduced-motion`（现有 globals.css 已处理，新动画需同样处理）。
3. **性能优先**：装饰动画全部走 CSS + 现有 `motion` 库，不新增依赖、不引入重型 canvas/particles。
4. **Server/Client 边界**：尽量保持服务端渲染；需要交互（hover、滚动、倒计时）的才标记 `"use client"`。

## 七、v3 视觉收敛优化（2026-08-26）

> 目标：保留「深空紫 + 玻璃 Bento + 萌宠」的品牌识别，减少无效装饰，提升首屏主体、信息层级与移动端阅读体验。

### 7.1 优先级与交付顺序

| 优先级 | 主题 | 目标 | 预计范围 |
|---|---|---|---|
| P0 | 首屏构图 | 让人物、标题和主 CTA 成为唯一视觉焦点 | `HomeHero.tsx`、`globals.css` |
| P0 | 表面与光效 | 提高卡片层级，减少全站同时发光 | `globals.css`、导航/按钮组件 |
| P1 | 内容密度 | 让数据和标签区域更易扫读 | `StatsCharts.tsx`、`TagCloud.tsx` |
| P1 | 移动端版式 | 优化窄屏标题、Banner 和 Hero 裁切 | `HomeHero.tsx`、`TourNotice.tsx`、`tour/page.tsx` |
| P2 | 动效节奏 | 降低持续动画的干扰和资源消耗 | `globals.css`、`FeedbackProvider.tsx` |

### 7.2 P0 · 首屏与视觉层级

- [x] **调整 Hero 遮罩**：底部遮罩从 `background/90` 降至 70–80%，保留文字可读性同时恢复人物和婚纱细节。
- [x] **缩小/后移萌宠**：桌面端大狗尺寸降低 15–20%，避免遮挡人物；移动端默认隐藏大型萌宠，仅保留小型装饰。
- [x] **建立单一主标题**：首页补充明确的品牌 `h1`，并把 Motto 降为辅助文案；避免水印文字承担标题职责。
- [x] **收敛光效**：默认卡片使用中性边框，紫色 glow 只用于 hover、active 和主 CTA。
- [x] **统一表面层级**：明确 `surface / surface-2 / surface-3` 的明度差，确保卡片不依赖阴影也能分组。

**验收标准**

- 首屏 3 秒内能识别「柏里挑怡」和两位成员，主标题/CTA 不被装饰抢焦点。
- Hero 人物面部和服装细节在深色主题下可辨识，卡片边界在无 hover 状态下仍清楚。

### 7.3 P1 · 数据与标签区域

- [x] **Tag Cloud 分层**：默认展示热度最高的 12–16 个标签，增加「展开全部」；字号限制为 2–3 档。
- [x] **颜色收敛**：标签颜色优先使用白/蓝/紫/玫瑰四个品牌色，减少无语义的彩色混用。
- [x] **提升图表对比度**：图表卡改用更明确的表面色，标题、坐标和次要文字分别建立清晰的亮度层级。
- [x] **移动端简化图表**：窄屏减少刻度和装饰动画，保留趋势、总数和关键分类。

**验收标准**

- 用户在 5 秒内能找到总数、趋势和主要分类，不需要依赖 hover。
- 375px 宽度下标签不造成连续多行噪声，图表标题与数值保持可读。

### 7.4 P1 · 移动端构图

- [x] **Hero 移动版**：隐藏大水印或降低透明度，重新设置图片 `object-position`，保证人物主体位于可视区域中心。
- [x] **巡演标题换行**：对 `PRIVATE SIGNAL 杭州站` 使用平衡换行和合理最大宽度，避免英文/中文孤行。
- [x] **Banner 自适应**：小屏将次要说明收起，保留活动名称、日期和一个 CTA；避免标题被截断成不可理解的省略号。
- [x] **固定移动导航**：保持当前横向导航结构，但给首尾增加渐变提示或提供“更多”入口，让用户知道仍可横向滑动。

**验收标准**

- 在 375px、390px、768px 三个宽度下无横向页面溢出，Hero、Banner、标题均不出现意外裁切。
- 首屏关键 CTA 位于拇指可达区域，内容不被固定导航遮挡。

### 7.5 P2 · 动效节奏与性能

- [x] **降低全屏噪点频率**：`cp-noise` 从 0.6 秒循环调整为 2–4 秒，或改为静态纹理。
- [x] **限制循环动画**：每个视图最多保留 1–2 个持续动画；光晕、渐变文字、边框 shimmer 不同时运行。
- [x] **粒子按需触发**：欢迎提示和导航粒子改为首次访问/主动交互触发，避免每次进入页面自动打断阅读。
- [x] **统一动效 token**：整理 enter/hover/exit 的持续时间和 easing，所有动画继续支持 `prefers-reduced-motion`。

**验收标准**

- 开启减少动画后页面仍保持完整层级和状态反馈。
- 首屏动画在 1.2 秒内完成，不持续抢占用户注意力；滚动时无明显掉帧。
